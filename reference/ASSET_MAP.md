# Asset map and provenance

This update is meant to be merged into the source root of the supplied `matyas-galda-portfolio-v1.zip`. It does not replace the existing project images or the FMK manifest.

The paper tile, hero backplate, edge rim and empty media mount were generated from the approved four-view visualization as reusable UI assets. The two cover treatments were derived from Matyáš Galda's supplied artwork and are for homepage thumbnails only; keep the originals visible in the detail galleries. The four transparent hero poses restore the earlier back-profile drawing concept and replace the v1 eight-frame set. Ferrugo remains represented by the official screenshot already in the source project.

The paper edges and textures are intentionally separate so they can adapt to a long desktop sheet and narrow mobile sheet. The edge strips are crops of the transparent rim asset. Use them at restrained opacity; the center of `sheet-edge-overlay.png` is genuinely transparent.

`reference/visual-revision-starter.css` is a starting set of overrides written for the v1 class names. It needs visual inspection and integration into `src/css/site.css`; it is not a finished substitute for the working build.

The target visualization shows only Last Breath and Forgotten Realms because Ferrugo was added later. The revised site must include Ferrugo third.
